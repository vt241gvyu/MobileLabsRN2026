# Лабораторна робота №5

## Побудова навігації у React Native із використанням Expo Router

## Мета роботи

Мета роботи - реалізувати навігацію в React Native застосунку за допомогою Expo Router. У проєкті зроблено публічні та захищені екрани, просту авторизацію через React Context, каталог товарів і динамічний маршрут для сторінки деталей товару.

## Інструкція запуску

Спочатку потрібно встановити залежності:

```bash
npm install
```

Потім запустити застосунок:

```bash
npx expo start
```

Після запуску застосунок можна відкрити через Expo Go на телефоні або через емулятор.

## Реалізований функціонал

- створено Expo-проєкт з Expo Router;
- реалізовано публічні екрани входу та реєстрації;
- створено AuthContext для збереження стану авторизації;
- реалізовано захищені маршрути;
- додано каталог товарів через FlatList;
- додано перехід на сторінку деталей товару через динамічний маршрут;
- реалізовано вихід з акаунту;
- додано сторінку для неіснуючих маршрутів.

## Структура основних файлів

- `app/_layout.jsx` - головний layout, у якому підключено `AuthProvider`.
- `app/(auth)/login.jsx` - екран входу користувача.
- `app/(auth)/register.jsx` - екран реєстрації з перевіркою паролів.
- `app/(app)/_layout.jsx` - layout захищеної частини застосунку.
- `app/(app)/index.jsx` - головний екран з каталогом товарів.
- `app/(app)/details/[id].jsx` - сторінка деталей товару за його `id`.
- `app/+not-found.jsx` - екран для неіснуючих маршрутів.
- `context/AuthContext.jsx` - контекст авторизації з функціями `login`, `register` і `logout`.
- `data/products.js` - тестові дані товарів.

## Висновки

Під час виконання лабораторної роботи було реалізовано file-based навігацію за допомогою Expo Router. Для авторизації використано React Context, у якому зберігається стан користувача. Також були створені захищені маршрути, які не відкриваються без входу в акаунт. У застосунку додано каталог товарів і динамічні сторінки деталей. У результаті вийшов простий застосунок з базовою навігацією та авторизацією.

## Відповіді на контрольні запитання

**Як перенаправити неавторизованого користувача в Expo Router?**

Можна перевірити стан авторизації в `_layout.jsx` і повернути `<Redirect href="/login" />`, якщо користувач не авторизований.

**Яка різниця між Link і router.push()?**

`Link` використовується як компонент у JSX, наприклад для посилання або кнопки. `router.push()` викликається в коді, наприклад після натискання кнопки або після виконання певної дії.

**Як працюють динамічні маршрути?**

Динамічний маршрут створюється через файл з квадратними дужками, наприклад `[id].jsx`. Значення `id` можна отримати через `useLocalSearchParams()`.

**Чому стан авторизації краще зберігати в React Context?**

React Context дозволяє використовувати стан авторизації в різних екранах без передачі props через багато компонентів. Так простіше перевіряти, чи користувач увійшов у застосунок.

**Для чого використовуються групи маршрутів?**

Групи маршрутів потрібні для логічного розділення екранів. Наприклад, `(auth)` використовується для входу і реєстрації, а `(app)` - для захищеної частини застосунку. Назва групи не додається до URL.
